# 🍫 Awesome Chocolate Shipments Dashboard  

An interactive **Power BI Dashboard** built to analyze chocolate shipment performance, sales trends, profitability, and regional distribution. This project provides business insights through visually rich analytics and KPI tracking.

---

## 📌 Project Overview  

This dashboard helps businesses monitor:

- 💰 Total Sales Amount  
- 📦 Total Boxes Shipped  
- 🚚 Shipment Distribution  
- 📈 Profit Percentage  
- 🌍 Geo-wise Sales Distribution  
- 🏆 Top Products & Salespeople Performance  

The dashboard is designed for **interactive business intelligence reporting** using **Power BI**.

---

- Monthly Total Amount
